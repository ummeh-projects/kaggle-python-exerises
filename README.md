# 🐍 Kaggle Python Exercises & Data Analysis

Welcome to my repository containing practice notebooks completed as part of Kaggle's Data Analysis & Python coursework. This repository showcases hands-on practice with core programming concepts and data manipulation techniques in Python.

---

## 📚 Covered Topics & Notebooks

Below is a summary of the topics covered in this repository:

1. **Arithmetic & Variables** (`exercise-arithmetic-and-variables.ipynb`)
   - Basic mathematical operations, variable assignments, and order of operations.

2. **Functions & Getting Help** (`exercise-functions-and-getting-help.ipynb`)
   - Writing custom functions, defining arguments, and utilizing built-in Python documentation.

3. **Data Types** (`exercise-data-types.ipynb`)
   - Working with strings, integers, floats, and booleans in Python.

4. **Conditions & Conditional Statements** (`exercise-conditions-and-conditional-statements.ipynb`)
   - Control flow using `if`, `elif`, `else` statements and logical operators.

5. **Lists & Operations** (`exercise-intro-to-lists.ipynb`)
   - List creation, indexing, slicing, and built-in list methods.
